# Безопасная смена — версия 3

Статический учебный тренажёр. Откройте index.html локально или опубликуйте содержимое каталога в корне GitHub Pages (Settings → Pages → Deploy from a branch → main / root). Сборка и сервер не нужны.

Вход: ФИО и группа, сохранение в localStorage. Таймер считает календарное время с начала регистрации, включая перерывы, и останавливается после успешного теста. 20 учебных ситуаций, 6 контрольных; порог 5/6. Сертификат — учебный, без юридической силы, печать / PDF средствами браузера. Данные не отправляются на сервер.

Нормативные ссылки и дата проверки: 25.11.2026. СП 12-135-2003 отменён с 01.01.2021; используется как исторический источник. Обновление текста заданий вручную.

Версия 3.1: изображения встроены в JavaScript; папка images сохранена для редактирования исходников, но не требуется для отображения. Загрузите все файлы в корень ветки main. После публикации обновите страницу Ctrl+F5.
